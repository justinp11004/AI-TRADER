# Day-trader seat (session structure) — per screen
Session clock + phase (pre/open/KZ-AM/lunch/KZ-PM/close) visible wherever entries or management happen.
Event blackouts surfaced BEFORE entry (pre-window per config), not after; countdown shown inside window.
Management rail truth: current state (WORKING/MANAGING), next planned action, partials plan, stop location with structural citation.
Day-loss ladder: soft/hard levels visible pre-entry; state transitions (reduced/halted) change the UI, not just a number.
Re-entry & cooldown rules honest: chasing/late-return flagged with the rule cited.
Flat-by-close personality: time-stop visible; converting horizon after entry is blocked and says so.
